<Steps>
  <Step title="Create an API key">
    Create a key under **API keys** at [mixetape.com](https://mixetape.com/api-keys) with the permissions the agent needs — see [API keys and permissions](/concepts/api-keys). Copy it; it is shown once.
  </Step>
  <Step title="Add the server">
    In `~/.codex/config.toml`:

    ```toml
    [mcp_servers.mixetape]
    url = "https://mixetape.com/mcp"
    bearer_token_env_var = "MIXETAPE_API_KEY"
    ```

    Then put the key in that variable, e.g. in your shell profile:

    ```sh
    export MIXETAPE_API_KEY="mxt_…"
    ```
  </Step>
  <Step title="Try it">
    Ask the agent to "list my mixetape channels". It calls `list_accounts` and answers with your connected channels. To add one from the agent, see [Connecting channels](/connect-an-agent/mcp#connecting-channels).
  </Step>
</Steps>
