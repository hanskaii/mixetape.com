**Connect:** a Pinterest account, personal or business. Pinterest may limit analytics to
business accounts; converting is free and keeps your Pins and boards.

**Posting:** Pinterest cannot hold a Pin, so mixetape creates it at `scheduledAt` (the lead is
always `0`). A video makes a video Pin (4 s–15 min), an image an image Pin, and 2–5 images
(`media`) one carousel Pin.

## Metadata

| Field | Notes |
|---|---|
| `boardId` | **Required.** A board id from `list_collections` |
| `title` | |
| `description` | Defaults to the post caption |
| `link` | Where the Pin leads when clicked |
| `altText` | |
| `thumbnailUrl` | Video Pins: public https cover image |
| `coverFrameSeconds` | Video Pins: cover frame, in seconds (default 1) |

## After it is up

Boards work as collections: list them, create one, and save a Pin to another board. Pin and
account analytics are available.
