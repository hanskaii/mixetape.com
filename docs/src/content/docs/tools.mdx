Each tool is an MCP tool of the same name and a REST endpoint, `POST /api/v1/tools/{name}`, taking the same JSON arguments. A key sees only the tools its [permissions](/concepts/api-keys) allow. Open a tool for its full input, output and examples.

## `read`

| Tool | Does |
|---|---|
| [`list_accounts`](/api/read/list_accounts) | The connected channels, their status and what each platform supports |
| [`list_posts`](/api/read/list_posts) | Posts, newest scheduled first; filter by status and time |
| [`get_post`](/api/read/get_post) | One post: status, error, platform link, attempts |
| [`get_post_insights`](/api/read/get_post_insights) | A post on the platform right now: visibility, processing, views, likes, comments |
| [`list_collections`](/api/read/list_collections) | Playlists (YouTube) or boards (Pinterest) |
| [`list_captions`](/api/read/list_captions) | The caption tracks of a post on the platform |

## `publish`

| Tool | Does |
|---|---|
| [`create_post`](/api/publish/create_post) | Schedule a post, or post now |
| [`update_post`](/api/publish/update_post) | Change a post that is still scheduled |
| [`cancel_post`](/api/publish/cancel_post) | Cancel a post that is still scheduled |
| [`retry_post`](/api/publish/retry_post) | Send a failed post again |
| [`set_thumbnail`](/api/publish/set_thumbnail) | Set or replace the thumbnail of a post on the platform |

## `manage`

| Tool | Does |
|---|---|
| [`edit_published_post`](/api/manage/edit_published_post) | Change the details of a post already on the platform |
| [`create_collection`](/api/manage/create_collection) | Create a YouTube playlist or a Pinterest board |
| [`add_to_collection`](/api/manage/add_to_collection) | Add a post on the platform to a playlist or board |
| [`upload_caption`](/api/manage/upload_caption) | Upload a subtitle track (SRT, or WebVTT on YouTube) |

## `comments`

| Tool | Does |
|---|---|
| [`list_comments`](/api/comments/list_comments) | Read a post's comments and replies, or those held for review |
| [`post_comment`](/api/comments/post_comment) | Comment on a public post as the channel |
| [`reply_to_comment`](/api/comments/reply_to_comment) | Reply to a comment as the channel |
| [`moderate_comment`](/api/comments/moderate_comment) | Publish, hold or hide a comment; optionally ban its author |

## `analytics`

| Tool | Does |
|---|---|
| [`get_post_analytics`](/api/analytics/get_post_analytics) | A post's views, watch time, retention and traffic sources |
| [`get_account_analytics`](/api/analytics/get_account_analytics) | A channel's totals, daily numbers, top posts and traffic sources |

## `storage`

| Tool | Does |
|---|---|
| [`create_upload`](/api/storage/create_upload) | A presigned URL to upload a file (up to 5 GB) in one PUT |
| [`import_file`](/api/storage/import_file) | Copy a file from a public URL into storage |
| [`list_files`](/api/storage/list_files) | The files in storage, with their r2:// URLs |
| [`delete_file`](/api/storage/delete_file) | Delete a file from storage |

## `channels`

| Tool | Does |
|---|---|
| [`connect_channel`](/api/channels/connect_channel) | Start connecting a channel: a sign-in link for the user |
| [`get_connection`](/api/channels/get_connection) | Where a connect attempt stands |
| [`choose_channels`](/api/channels/choose_channels) | Add the channels the user picked from a sign-in |
