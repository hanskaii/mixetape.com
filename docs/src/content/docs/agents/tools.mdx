A key sees only the tools its [permissions](/concepts/api-keys) allow. The icons show where a
tool works: most work on every platform; the ones that depend on a platform feature —
playlists and boards, captions, comments, account analytics — show the platforms that have it,
and answer with an error for an account or post elsewhere.

This page is generated from the catalog the server publishes at
[`/mcp/tools.json`](https://mixetape.com/mcp/tools.json), so it always matches what agents see.
