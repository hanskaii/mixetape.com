---
title: Claude Code
description: "Add mixetape to Claude Code as an MCP server, so Anthropic's terminal coding agent can schedule, move and cancel your social posts."
sidebar:
  order: 1
---

<Steps>
  <Step title="Add the server">
    ```sh
    claude mcp add --transport http mixetape https://mixetape.com/mcp -s user
    ```

    `-s user` makes it available in every project; leave it out to add it to the current
    one only.
  </Step>
  <Step title="Sign in">
    In Claude Code, run `/mcp`, pick **mixetape** and choose to authenticate. A browser tab
    opens on mixetape: sign in, tick the [permissions](/concepts/api-keys) the agent gets and
    press **Allow**. Claude Code keeps the access fresh by itself.
  </Step>
  <Step title="Try it">
    Ask the agent to "list my mixetape channels". It calls `list_accounts` and answers with your connected channels. To add one from the agent, see [Connecting channels](/agents#connecting-accounts).
  </Step>
</Steps>

<Aside type="note" title="With an API key instead">
  For a headless run (CI, a routine), create a key under **API keys** and add the server with
  `--header "Authorization: Bearer mxt_…"`; nothing then needs a browser.
</Aside>

<Aside type="tip">
  In a session that was already running, reconnect the server (`/mcp`) or start a new one
  to see the tools.
</Aside>
